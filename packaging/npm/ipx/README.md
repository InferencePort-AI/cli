# @inferenceport/ipx

The InferencePort AI command line, installed through npm.

```bash
npm install -g @inferenceport/ipx
ipx --help
```

The package is a small launcher; the real program is a native binary delivered through a per-platform
optional dependency (`@inferenceport/ipx-<os>-<cpu>`), so **no Python or other runtime is required**.

Docs: https://inferenceport-ai.readthedocs.io — source: https://github.com/inferenceport-ai/cli
